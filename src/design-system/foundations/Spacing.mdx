# Spacing and layout

## Space scale

`--space-N` is N quarter-rems (`--space-4` = 1rem = 16px). Use it for every margin, padding and gap; compositions take it through custom properties such as `--flow-space` and `--gap`.

## Section padding

`Section size` picks the `.region` padding: `lg` = `--space-24` (default), `md` = `--space-20`, `sm` = `--space-16`. The gap after a section header is `--space-16` unless the section sets `--flow-space`.
