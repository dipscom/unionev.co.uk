# Spacing and layout

## Space scale

The scale is fluid (Utopia style). Each step is a multiple of a base that grows from 16px at a 375px viewport to 22px at 1280px, and stays put outside that range. Every step grows ×1.375 between the two, so spacing needs no breakpoints: pick one step and it adapts.

Use it for every margin, padding and gap; compositions take it through custom properties such as `--flow-space` and `--gap`. As a guide: `3xs`–`xs` inside components (labels, icons, small controls), `s`–`l` for component padding and gaps between items, `xl`–`3xl` between blocks and for page bands.

The first two bars show each step at 375px and 1280px; the third is its size at the current width of this page.

## Section padding

`Section size` picks the `.region` padding: `lg` = `--space-3xl` (default), `md` = `--space-2xl`, `sm` = `--space-xl`. The gap after a section header is `--space-2xl` unless the section sets `--flow-space`.
