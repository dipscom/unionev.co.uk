## Type scale

Each `--text-*` size pairs with a `--leading-*` line height of the same name where one exists. The utilities `.text-xs`, `.text-sm` and `.text-lg` set both.

### Relative line heights

<table>
	<tbody>

				<tr key={t.name}>

						<code>{t.name}</code>

				</tr>
			))}
	</tbody>
</table>

`--leading-snug` is the body default; `--leading-tight` the heading default; `.leading-relaxed` is for longer paragraphs such as leads and FAQ answers.

## Rules

- No literal `font-size` or `line-height` in blocks: use the scale. `--text-13` and `--text-15` exist for a few dense components.
- Headings follow the document outline (one `h1` per page, an `h2` per section, `h3` inside), whatever their visual size.
