# Utilities

Single-purpose classes from `src/styles/utilities.css`. **Add a utility only once it is used three times**; until then the declaration stays in the block. A block must not set a property that a utility on the same element controls, because the block would win.

## Context and helpers

| Class              | Does                                                                                                                                |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| `.theme-dark`      | Reassigns the colour roles for a dark background (see Foundations / Colour). Pair with `.bg-brand`, or the hero/footer backgrounds. |
| `.visually-hidden` | Hidden on screen, read by screen readers                                                                                            |
| `.img-fill`        | Makes an `Image` fill a sized wrapper (`object-fit: cover`)                                                                         |

## Exceptions are data attributes

Variants and states are attributes, not modifier classes: `data-variant="outline"`, `data-size="sm"`, `data-state="failed"`, `data-layout="thirds"`, `data-title-size="md"`. State from JavaScript is an attribute too (`aria-expanded`, `hidden`, `aria-invalid`).

```html
<a class="btn" data-variant="outline" data-size="sm" href="#case-study">See the case study</a>
```
