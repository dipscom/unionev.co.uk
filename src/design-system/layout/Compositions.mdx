# Compositions

Layout primitives from `src/styles/compositions.css` ([CUBE CSS](https://cube.fyi)). They arrange their children and know nothing about what is inside. Tune them with custom properties on the same element, and order classes block, composition, utility: `class="card flow text-center"`.

## `.wrapper`

A centred column that owns the page gutter. `--wrapper-max` sets the content width (default `--w-6xl`).

<Demo>
	<div
		className="wrapper"
		style={{ '--wrapper-max': '20rem', background: 'var(--color-surface-alt)' }}
	>
		<Box>--wrapper-max: 20rem</Box>
	</div>
</Demo>

## `.region`

A page band: vertical padding from `--region-space` (default `--space-24`) and `scroll-margin-top` for the fixed nav. `Section` is a `.region`.

## `.flow`

Vertical rhythm: a margin above every child but the first, from `--flow-space` (default `1em`). Give every `.flow` its own `--flow-space`, because custom properties inherit.

<Demo>
	<div className="flow" style={{ '--flow-space': 'var(--space-6)' }}>
		<Box>One</Box>
		<Box>Two</Box>
		<Box>Three (--flow-space: var(--space-6))</Box>
	</div>
</Demo>

## `.cluster`

A wrapping row, centred by default. `--cluster-gap`, `--cluster-justify`, `--cluster-align`.

<Demo>
	<div className="cluster" style={{ '--cluster-justify': 'flex-start' }}>
		{[
			'Everything handled',
			'Fully funded options',
			'Revenue share',
			'One point of contact',
			'UK-wide'
		].map((t) => (
			<Box key={t}>{t}</Box>
		))}
	</div>
</Demo>

## `.repel`

Pushes items to opposite ends (`--repel-gap`, `--repel-align`). `data-stack-below="md"` stacks them until 768px, as the footer does.

<Demo>
	<div className="repel">
		<Box>Logo</Box>
		<Box>Menu</Box>
	</div>
</Demo>

## `.switcher`

A column that becomes a row from 640px (`--switcher-gap`, `--switcher-justify`, `--switcher-wrap`). Used for button pairs.

<Demo>
	<div className="switcher">
		<Box>Primary action</Box>
		<Box>Secondary action</Box>
	</div>
</Demo>

## `.with-icon`

An icon beside its text, top-aligned (`--with-icon-gap`, default `--space-3`). Check lists and feature cards use it.

<Demo>
	<div className="with-icon">
		<span className="color-accent" style={{ display: 'flex' }}>
			<svg
				width="20"
				height="20"
				viewBox="0 0 24 24"
				fill="none"
				stroke="currentColor"
				strokeWidth="2"
				strokeLinecap="round"
				strokeLinejoin="round"
				aria-hidden="true"
			>
				<path d="M20 6 9 17l-5-5" />
			</svg>
		</span>
		<span>
			Text that wraps onto several lines stays aligned to the right of the icon, which sits on the
			first line.
		</span>
	</div>
</Demo>
